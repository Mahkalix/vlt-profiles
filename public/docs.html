SET UP YOUR PC.

The website needs a local Windows connector to access your saved profiles and the Riot Client session. Keep the connector running while using the app.

  1. Install Node.js 22 or newer and PowerShell 7.
  2. Download and extract the connector ZIP. Run Demarrer.cmd from the extracted folder. It opens the local app in your browser.
  3. Sign in to your source account in Riot Client. Select Detect Riot account and check the displayed account.
DOWNLOAD CONNECTOR ↓

Using the hosted website? Select Connect my PC with the connector running. Allow local network access if your browser asks. If that connection fails, use the local interface opened by the connector.

TRANSFER SETTINGS.
KEEP YOUR FEEL.

  1. Sign in to your source account in Riot Client and select Detect Riot account.
  2. Select Save current settings, name your profile and save it. Each save creates a new version.
  3. Switch to your destination account in Riot Client. Close VALORANT, but keep Riot Client signed in.
  4. Detect the account again. Verify the destination name, then select Apply on the saved source profile.
  5. Confirm the destination. Wait for the success message before launching VALORANT.

The connector backs up the destination settings before writing, then reads the settings back from Riot to verify the transfer.

A WAY BACK.

Restore previous settings

Sign in to the account you want to restore, close VALORANT, and detect that account. Select View backups, choose a backup and confirm Restore. Backups are filtered by the detected account, and a restore creates another backup first.

Remove a saved profile

Select Delete beside a profile, then confirm. This removes the profile from the library without changing any account settings or transfer backups. A copy is kept in Profils-Supprimes inside the data folder.

BACK IN ACTION.

My PC will not connect

Check that the connector is running. Start Demarrer.cmd again if necessary. On the hosted site, allow local network access if prompted, or use the local interface while the connector is running.

I see 401 or an expired pairing message

The connector generates a new pairing code when it restarts. Click Connect my PC again to renew the association.

The wrong Riot account is displayed

Switch accounts in Riot Client and select Detect Riot account. Do not apply a profile until the destination is correct.

Apply is disabled

Make sure a Riot account is detected, VALORANT is closed, and no other operation is running. Detect the account again after closing the game.

Settings did not transfer

Check that the app reported a verified transfer and that you launched the destination account. Only synchronized preferences are covered. Local-only settings may not transfer. If an operation fails, check the account before retrying and keep the backup.

LOCAL BY DESIGN.

Profiles and backups are stored in %LOCALAPPDATA%\VLTProfiles. They survive browser refreshes and PC restarts. They are not a cloud backup: copy this folder somewhere safe before changing or resetting your PC.

  • Profils-Cloud: saved settings profiles.
  • Sauvegardes-Cloud: backups created before transfers.
  • Profils-Supprimes: profiles removed from the library.

Riot session credentials stay in the local connector and are not sent to the Vercel site. Settings are read from and written to Riot through a private API. This is an unofficial integration, not an approved Riot service, and availability is not guaranteed.
